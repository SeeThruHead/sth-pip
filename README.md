# SthPiP

Always-on-top webcam picture-in-picture overlay for macOS. Show your face over screen shares and recordings.

## Install

```
brew install seethruhead/tap/sth-pip
```

## Usage

- **Left-click** the menu bar icon to toggle camera on/off
- **Right-click** for Open at Login and Quit
- Drag to move, edges to resize

## Amethyst

Add `com.sth.pip` to your floating list so it doesn't get tiled.
